# NOCTURNE RHYTHM — Gothic Ink Edition (better16)

Браузерная ритм-игра: беги по дорожке, прыгай в такт бочке, собирай монеты,
кувыркайся в воздухе. Полностью статический сайт — работает на GitHub Pages
без всякого сервера.

## Что нового в better16

- **Работа на GitHub Pages** — никаких start.bat / server.py: всё статикой.
- **Онлайн-мультиплеер через интернет** (WebRTC/PeerJS): создатель комнаты —
  хост, загружает свой трек, он передаётся напарнику вместе с картой битов.
- **3 визуальных стиля всей игры** (меню → ⚙ НАСТРОЙКИ):
  I «Готические Чернила», II «Неоновый Пульс», III «Ледяной Витраж».
- **Финал трека**: последние ~10–24 сек — нарастающий эффект (крещендо),
  монеты ×2, вспышка в конце и ранг S/A/B/C.
- **Сворачиваемый заголовок** NOCTURNE RHYTHM (стрелочка справа сверху).
- **Пауза при сворачивании**: если игрок свернул страницу, матч замирает у
  обоих, у напарника надпись «ПОДОЖДИТЕ, ВАШ НАПАРНИК СВЕРНУЛ СТРАНИЦУ».
- **Настройки в меню**: стиль, качество частиц, тряска экрана.
- +2 скина (Ледяная Дева, Нео-Ронин), +2 предмета (Око Бури, Звёздная Цепь),
  серии- milestones, ранги, прогресс-бар передачи трека.

## Публикация на GitHub Pages

1. Используй свой репозиторий (например, `gamemusic`) на аккаунте `yarofavq`.
2. Загрузи в корень репозитория **содержимое этой папки**, полностью заменив
   старые файлы (index.html, всё содержимое src/ и т.д.).
3. Settings → Pages → Source: `Deploy from a branch`, Branch: `main`, `/ (root)` → Save.
4. Через 1–2 минуты игра будет на `https://yarofavq.github.io/gamemusic/`.

Важно: мультиплееру нужен HTTPS — на GitHub Pages он есть. Локально для
теста: `python -m http.server 8080` в папке игры (file:// не подойдёт — ES-модули).

## Мультиплеер

- Хост: «ИГРА С ДРУГОМ» → «СОЗДАТЬ КОМНАТУ» → получает код из 4 символов.
- Гость: тот же сайт → «ИГРА С ДРУГОМ» → вводит код → «ВОЙТИ».
- Хост выбирает трек — он анализируется, отправляется гостю и стартует отсчёт.
- Соединение P2P через бесплатные серверы-брокеры PeerJS (нужен интернет).
  Код комнаты резолвится через брокер, поэтому друг может зайти с ЛЮБОЙ сети
  (мобильный интернет, работа, вуз) — плюс STUN/TURN для жёстких NAT.
- Если кто-то свернул страницу — игра у обоих на паузе, пока он не вернётся.

## Управление

- Пробег: `Space` / `↑` / `W` / клик — прыжок в бит.
- В воздухе: второй прыжок — кувырок (флип, бонус ×1.5 к оценке).
- Монеты падают в апексе прыжка, точное попадание в бочку = PERFECT ×2.

## better19 — что нового

- Конец трека больше не показывает экран проигрыша: после TRACK CLEAR-взрыва
  игра сама плавно возвращает в меню (фейд-переход + тост «ТРЕК ПРОЙДЕН —
  ДОБЫТО +N МОНЕТ» + анимация казны). Экран «ЧЕРНИЛА ПРОЛИТЫ» остался
  только для настоящих столкновений и дуэлей.
- Фикс лагов других тем: неоновый шейдер стал в ~2.3 раза легче (7 → 3
  выборки текстуры на пиксель), витраж — на треть (3 → 2); тяжёлый статичный
  фон (скайлайн с окнами + звёзды) запекается в офскрин-канвасы один раз на
  тему и рисуется тремя drawImage вместо ~600 операций за кадр.
- Адаптивное разрешение: игра сама следит за FPS и плавно снижает/повышает
  внутреннее разрешение рендера (100% → 60%), удерживая ~60 fps на слабых
  видеокартах и в браузере без железного ускорения.
- Детализация фона зависит от настроения «ЧАСТИЦЫ» (НИЗ/СРЕД/ВЫС): звёзды,
  светлячки, нетопыри, кометы, колонны собора.
- FEVER при серии x20+: край дороги вспыхивает багровым, магнит монет
  шире, порталы дают ×1.5 монет.
- Пыль приземления после прыжка (сила зависит от скорости падения).
- Мелкие оптимизации: кэш DOM-элементов горячего цикла, честный dt для
  комет/молний (убран хардкод 0.016), меньше мусора для GC.

## better20 — что нового

- ГЛАВНЫЙ ФИКС: после конца трека / возврата в меню игра больше не «умирает».
  Причина была в том, что взрыв TRACK CLEAR выходил из игрового цикла до
  планирования следующего кадра — рендер-цепочка рвалась навсегда: музыка
  играла, но картинка стояла. Теперь следующий кадр планируется ПЕРВЫМ
  действием цикла + каждый кадр защищён try/catch (одна сломанная фигня не
  может заморозить игру).
- Убран мусорный оператор в обработчике прыжка: он кидал ReferenceError на
  каждом зачётном прыжке — из-за этого не появлялись всплывашки PERFECT/FLIP,
  не обновлялся счётчик серии и индикатор бита («на некоторых героях после
  прыжка игра не работает»). Теперь зачётный прыжок честно красит HUD.
- КОМНАТА ЖИВЁТ ПОСЛЕ ПОБЕДЫ/ПРОИГРЫША: кнопка «МЕНЮ» больше не разрушает
  P2P-соединение. В меню показывается «КОМНАТА АКТИВНА: КОД» — хост грузит
  новый трек, матч перезапускается автоматически. Разорвать комнату можно
  только явной кнопкой «ПОКИНУТЬ КОМНАТУ» (и сменой режима на «ОДИНОЧНАЯ»).
  Плюс защита от двойного старта матча при повторной загрузке трека.
- СПЕКТЕЙТ ПОСЛЕ СМЕРТИ: в дуэли после твоей смерти матч продолжается —
  камера следит за призраком друга, мир скроллится, музыка играет. Зум —
  колесиком мыши, а на телефоне кнопками «+» и «−» в верхней панели.
  Твой упавший герой растворяется в чернилах, счёт замирает (мёртвый не
  зарабатывает). Результат дуэли приходит прямо в панель наблюдения.
- ЧЕСТНЫЙ СЧЁТ ХОСТ/ГОСТЬ: пассивные очки теперь капают по ЧАСАМ ТРЕКА, а
  не по кадрам — телефон на 30 fps зарабатывает ровно столько же, сколько
  ПК на 144 fps. (Проверено автотестом: разница очков хоста и гостя при
  одинаковых нажатиях — 1-4%, а не x2.)
- Мелочи: после конца трека мир больше не телепортируется к началу на
  время взрыва; панель прогресса трека видна и мёртвому наблюдателю.

## better21 — что нового

- **Фикс «при прыжке всё ломается»**: у «Вестника Ворона» глаз рисовался с
  отрицательным радиусом в момент прыжка (canvas-исключение убивало кадр).
  Исправлено, плюс теперь ЛЮБОЙ сбой отрисовки скина/фона изолирован и не
  может заморозить игру — проверено автотестом на всех 24 скинах.
- **Телефоны больше не лагают**: на мобильных автоматически включается лёгкий
  режим (меньше частиц и деталей фона, урезанное разрешение рендера, более
  агрессивный адаптивный governor). Ваш ручной выбор качества в настройках
  сохраняется и приоритетнее.
- **Громкость сохраняется** между сессиями (слайдер в меню и в HUD — общий).
- **КРАСИВЕЙШИЙ ВИЗУАЛ** (Настройки): свечение на любой теме, плотнее фон и
  частицы (+50%), длинные шлейфы, кинематографичный пост-процесс (блум,
  дышащая виньетка, глиттер). Красиво, но требовательно — отключается тем же
  тумблером.
- **Собственные слайды**: если меню/настройки не влезают в экран, появляются
  аккуратные готические полосы прокрутки и мягкие тени «листай вверх/вниз».
